# @kobayami/graphity

All of Graphity in one package: it re-exports everything that `@kobayami/graphity-core`, `@kobayami/graphity-controlflow`, `@kobayami/graphity-dot` and `@kobayami/graphity-mermaid` export, at the version of this package. It has no code of its own.

It is a package of [Graphity for TypeScript](https://github.com/kaufco/graphity-ts#readme), which is the TypeScript implementation of the Java library [Graphity](https://github.com/kaufco/graphity). Its counterpart in Java is the module `graphity`. The [README](https://github.com/kaufco/graphity-ts#readme) of the repository shows how to use it and how its API relates to Java's.

```bash
npm install @kobayami/graphity
```
