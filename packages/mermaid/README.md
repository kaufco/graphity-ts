# @kobayami/graphity-mermaid

This package is a writer of Mermaid flowcharts for Graphity graphs, with labels, shapes, classes, styles and clusters taken from your own arrays by node ID and edge index. Mermaid flowcharts render in Markdown.

It is a package of [Graphity for TypeScript](https://github.com/kaufco/graphity-ts#readme), which is the TypeScript implementation of the Java library [Graphity](https://github.com/kaufco/graphity). Its counterpart in Java is the module `graphity-mermaid`. The [README](https://github.com/kaufco/graphity-ts#readme) of the repository shows how to use it and how its API relates to Java's.

```bash
npm install @kobayami/graphity-mermaid
```
