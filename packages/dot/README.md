# @kobayami/graphity-dot

This package is a writer of DOT (the language of Graphviz) for Graphity graphs, with labels, attributes and clusters taken from your own arrays by node ID and edge index.

It is a package of [Graphity for TypeScript](https://github.com/kaufco/graphity-ts#readme), which is the TypeScript implementation of the Java library [Graphity](https://github.com/kaufco/graphity). Its counterpart in Java is the module `graphity-dot`. The [README](https://github.com/kaufco/graphity-ts#readme) of the repository shows how to use it and how its API relates to Java's.

```bash
npm install @kobayami/graphity-dot
```
